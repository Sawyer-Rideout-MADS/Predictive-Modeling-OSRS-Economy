# Predictive-Modeling-OSRS-Economy
An attempt to generate a comprehensive model of the in-game economy of the online multiplayer video game "Old School RuneScape."

Old School RuneScape (OSRS) has a widely utilized trading feature, in which players exchange virtual gold with each other for virtual items within the game. Items are priced at differing gold values based on their difficulty to obtain, their rarity, and their utility, among other aspects. This project is an attempt to use macroeconomic principles to attempt to predict changes in certain high trade-volume items.
